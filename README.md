# 2D Pixel Art

2D Pixel Art is a browser-based editor for creating artwork on a fixed 40 × 40 pixel grid. It is built with React, TypeScript, Vite, and Tailwind CSS and runs entirely in the browser.

[Open the live editor](https://mjollnir03.github.io/2D-Pixel-Art/)

## Features

- Pen, eraser, and bucket-fill tools
- Custom pen and canvas colors
- Mouse, touch, and stylus drawing
- Grid toggle plus undo and redo
- PNG import and export

## Run locally

```bash
cd main
npm ci
npm run dev
```

The application source and detailed project notes are in [`main/`](main/README.md).
